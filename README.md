# 🌦️ Weather Dashboard

A modern and responsive Weather Dashboard built using HTML, CSS, and JavaScript. It fetches real-time weather data using the OpenWeather API.

## ✨ Features

- 🔍 Search weather by city
- 🌡️ Real-time temperature
- 💧 Humidity
- 💨 Wind Speed
- 🌅 Sunrise & Sunset
- 👁️ Visibility
- 🌤️ Weather Icons
- 📱 Responsive Design
- 🎨 Glassmorphism UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeather API

## ⚙️ Installation

1. Clone the repository
2. Open `index.html`
3. Add your OpenWeather API key in `script.js`
4. Run the project in your browser
